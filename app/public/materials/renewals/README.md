# Northstar renewal-window lab

This ZIP contains a faulty starter and a separate reference solution. All data and account names are synthetic. The exercise has no credentials, network calls, package installation, external writes, commits, or pushes.

1. Begin in `starter/`.
2. Run `python3 -m unittest discover -s tests -v`.
3. Add the day-30 regression test before changing the implementation.
4. Confirm that the new test fails.
5. Make the smallest implementation change.
6. Run the focused test and the full suite.
7. Review the diff and leave the exercise uncommitted.

Use `REFERENCE_FIX.md` only after the learner has stated the acceptance criteria and proposed a test.
